# SWYNEX Business Intelligence Case Study

## Project Overview
This project was completed as Task 4 of my Power BI internship at SWYNEX Technologies. It presents a business intelligence case study based on a Logistics & Delivery Performance Dashboard.

## Business Question
How can a business monitor sales, product profitability, regional performance, and delivery status using an interactive Power BI dashboard?

## Tools Used
- Microsoft Power BI
- DAX
- Data Modeling
- Data Visualization

## Dashboard Features
- Total Sales, Total Profit, Average Sales, and Total Orders KPI cards
- Sales by Region
- Profit by Product
- Delivery Status donut chart
- Interactive Region and Delivery Status slicers

## Key Insights
1. North is the highest-sales region in the dashboard.
2. South has the lowest displayed sales among the four regions.
3. Laptop leads the displayed Profit by Product ranking.
4. Most orders are marked Delivered.
5. Cancelled and In Transit orders can be reviewed for follow-up.

## Recommendations
- Investigate sales differences between regions.
- Review product-level profitability.
- Monitor cancelled and in-transit orders.
- Use interactive filters to explore performance.

This project demonstrates how an interactive Power BI dashboard can help present logistics performance metrics and support business analysis.
